# Einstein X Física Quântica!

Vamos usar o conhecimento de **Einstein** e da **física quântica** para entender o mundo Quântico. Quem está certo?

Vamos encontrar os pontos de divergência entre Einstein e a física quântica.

 Para isto usaremos o apoio da NotebookLM para criar uma base de fontes confiáveis e faremos várias perguntas para tentarmos encontrar os conflitos e vermos como Einstein responderia a estas perguntas.
